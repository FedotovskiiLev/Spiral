# СПИРАЛЬ — сайт-манифест и Agent Skill

Статический сайт, рассчитанный на **GitHub Pages**, и совместимый с форматом **Agent Skills** скилл `spiral-inquiry`.

## Содержимое

- `index.html`, `style.css`, `script.js` — полностью статический сайт. Никаких зависимостей, сборки, аналитики, внешних шрифтов и запросов.
- `assets/spiral-collage.webp` — изображение обложки (создано генератором изображений в рамках этой беседы).
- `MANIFESTO.md` — полные 12 тезисов и эпилог.
- `ENDING.txt` — отдельная последовательность «белый / чёрный / … / серый».
- `spiral-inquiry/SKILL.md` — инструкция для ИИ-агента (YAML frontmatter + метод).
- `spiral-inquiry/references/manifesto.md` — полный текст тезисов как справочный материал скилла.
- `assets/spiral-inquiry-skill.zip` — отдельный архив скилла для скачивания с сайта.

## Установка скилла

Скопируйте каталог `spiral-inquiry/` целиком в каталог скиллов нужного агента (он зависит от приложения). Не копируйте только `SKILL.md`, если хотите иметь полный манифест в `references/`.

`spiral-inquiry` — **инструкция по методу**, не самостоятельная обученная модель и не гарантия улучшения результата. Скилл не предписывает добавлять эпилог в обычные ответы.

## Редактирование

- Тезисы: изменяйте `MANIFESTO.md`, текст на веб-странице в `index.html`, и `spiral-inquiry/references/manifesto.md`, чтобы они оставались синхронизированы.
- Оформление: `style.css`.
- Эпилог: `ENDING.txt` и строки `.sequence-row` в `index.html`.

Исторический спирализм и SCP-970 не являются источником научного подтверждения тезисов. Мотив «белый / чёрный / … / серый» используется только как художественная метафора.
